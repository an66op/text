# 共鸣 · 运营工作台

独立 React 19 + Vite + TypeScript 应用，默认端口 **5174**。与前台共享开发依赖，部署时产出独立 `admin/dist`，不依赖前台页面。所有运营数据和写操作使用 Go API，界面不会用本地假数据兜底成功。

## 本地启动

先在仓库根目录安装依赖并启动 Go API，随后运行：

```sh
npm run dev --prefix admin
```

打开 `http://localhost:5174`。Vite 将 `/api` 代理至 `http://127.0.0.1:8080`，保留请求 Origin。API 必须允许当前开发 Origin。会话依赖 HttpOnly Cookie，前端没有令牌存储。

开发环境启用种子后，可点击“填入示例”，再手动登录：`admin@gongming.local` / `Admin2026!`。成员示例账号无法进入运营工作台。**生产必须禁用默认凭据与开发种子**，通过同源反向代理提供 `/api`，并为各路由设置 SPA fallback。构建时可设置 `VITE_FRONTEND_URL` 为正式前台地址；默认开发链接使用当前主机的 5173 端口。

## 页面与权限

| 路由        | 功能                                                                   |
| ----------- | ---------------------------------------------------------------------- |
| `/login`    | 登录、示例填入、密码可见性、失效会话提示                               |
| `/overview` | 用户、内容、活跃和举报指标，真实日趋势、表格明细、最近审计             |
| `/users`    | 服务端搜索 / 状态与角色筛选 / 分页，资料详情、安全确认后修改状态和角色 |
| `/content`  | 服务端搜索 / 状态筛选 / 分页，阅读完整帖子后发布、隐藏或转待审核       |
| `/reports`  | 工单筛选、核实对象、必填处理说明、二次确认处理或驳回                   |
| `/audit`    | 服务端搜索 / 分页、只读审计详情                                        |
| `/system`   | Go 健康检查、版本 / 存储 / 环境 / 运行时长、能力和实验边界             |

列表的 `q`、`status`、`role`、`offset` 与 `detail` 使用 URL 参数，刷新可恢复搜索、页码和当前详情。详情所在页保留在 URL；已变更或不在该列表的记录会明确提示。

管理员与审核员可读运营数据、审核内容和处理举报；用户状态与角色变更仅限管理员。当前账号在 UI 中不可修改自身状态与角色，最后管理员保护由服务端最终执行。敏感用户编辑必须输入账号标识确认。写操作不乐观伪造成功，收到服务端成功响应后才更新列表。

举报工单结论与对象审核分别管理：处理工单不会自动隐藏内容或封禁用户。系统页明确说明测试 GEM、AI / 支付 / 链上真实接入边界。登录后环境标识从服务端实时读取。`dailyActive` 当前服务端统计口径是持有有效会话的账号数，UI 标注为“有效会话用户”；趋势按 UTC 日聚合，操作时间显示中国标准时间。

## 检查

```sh
npm run typecheck --prefix admin
npm run test --prefix admin
npm run build --prefix admin
```

测试覆盖 Cookie 请求 / 401 失效 / 403 拒绝 / 坏响应、分页与跳转安全、成员权限、审核员只读、角色二次确认、失败写入、内容审核与举报提交、趋势明细。测试夹具仅存在于测试文件，运行页面始终从 API 读取。

API 契约见仓库 `docs/API_CONTRACT.md`。生产部署还需 HTTPS、正确的 Cookie 属性、独立数据库 / 密钥、备份恢复、真实外部服务接入与完整的部署验收。
