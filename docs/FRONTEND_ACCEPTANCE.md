# 2026-10-09 页面化验收记录

本文件保留上一轮页面化验收。2026-10-15 视觉重设计的规则与最新预览见 [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md)，下文的微信式视觉及旧截图属于历史记录。

## 流程与数据

- 社交包含好友申请接受/拒绝、备注标签、群公告/成员/邀请/退出、聊天搜索、草稿恢复、图片和文件详情、文件下载、消息引用/删除/撤回及模拟通话。测试数据为 15 位基础好友、6 位推荐用户和 8 个群，旧记录通过一次性迁移补齐。
- 内容包含动态/世界发布、封面修改、用户主页、评论回复、自帖管理、短视频评论、书籍详情/目录/书架/阅读偏好、三款可玩游戏与成绩、组织创建管理与活动报名、直播聊天以及视频选集/弹幕/进度。
- 设置包含资料头像编辑、账号、安全码演示、设备、隐私、通知、内容偏好、黑名单与数据导出。消息摘要隐藏、默认动态范围、黑名单及播放偏好与相应页面贯通。其余服务端相关选项明确作为本机演示偏好保存。
- 钱包包含多币模拟资产、转账填写→确认→结果、收款二维码、兑换、资产及交易详情。浏览器已实际验证确认页刷新后仍可提交，结果与余额写入本地数据。
- 已修复昵称碰撞导致错误帖子归属、同名组织与书架串扰、删评论后正在编辑的回复丢失、同一转账草稿重复扣款，以及提交后跳转导致本地表单未保存的问题，并加入回归测试。

## 工程与浏览器证据

本轮工程检查结果：119 项测试通过，类型检查、ESLint、生产构建和 Prettier 检查通过。测试跟随相应 feature，可运行 `npm run check` 与 `npm run format:check` 复验。

浏览器已验证聊天草稿刷新恢复、社交→聊天资料→联系人→聊天、图片详情、转账填写→确认刷新→结果、小说详情→加入书架→阅读翻章→刷新→阅读设置。

响应式检查覆盖 360px、390px、430px 手机和 1280px 桌面。动态、设置、转账、书架、短视频、组织与直播详情在 360/430/1280px 的 21 组检查中均无横向溢出、无业务弹窗、无底部主菜单。

预览文件位于项目根目录：`preview-full-chat-panel.jpg`、`preview-full-activity.jpg`、`preview-full-settings.jpg`。手机软键盘、实际 iOS 安全区、断网与真实后端能力仍需下一阶段单独验收，计划见 [NEXT_PHASE.md](NEXT_PHASE.md)。
