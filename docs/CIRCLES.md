# 本机圈子演示

本文描述保留的本机演示，目录在 `/circles/demo`，创建在 `/circles/demo/new`。真实社区入口是「发现 → 圈子」及 `/circles`，创建、成员、频道、帖子和圈图已由Go/PostgreSQL授权；见 [圈子服务说明](CIRCLES_SERVICE.md)。两套数据互不替代，也不在登录时导入。

本机首页以圈主资料、成员关系、置顶与动态流为中心；文字交流、活动、语音和资料保留为独立体验。

## 使用路径

1. 打开 `/circles/demo`，切换「我的 / 发现」，搜索圈子并按兴趣分类筛选。
2. 示例 `/circles/organization-photography` 展示「街头摄影散步」。当前演示身份是该圈子的管理员，可以体验管理入口。
3. 首页提供「全部 / 精华 / 圈主 / 相册」筛选和最新、最热排序，点赞与回复直接衔接详情。筛选写入 URL，打开详情返回后仍保留。
4. 群聊、活动、资料、成员在首页快捷进入；更多圈内空间由手机顶部菜单和桌面侧栏进入。
5. 创建自己的圈子后，当前身份为圈主，可编辑圈子、创建频道、查看邀请链接、管理成员与解散圈子。管理员可在动态详情设置精华和置顶，帮助成员找到长期内容。

文字消息、帖子、点赞、评论和活动报名保存到当前浏览器。邀请链接包含本地演示邀请码，可在当前浏览器测试加入流程。语音房提供加入、离开、静音与耳机开关的交互演示，不建立真实语音连接。

## 角色与权限

| 身份   | 能力                                                                           |
| ------ | ------------------------------------------------------------------------------ |
| 访客   | 查看公开圈子介绍，通过公开入口或邀请码加入                                     |
| 成员   | 阅读成员频道、发消息、讨论发帖、点赞评论、活动报名、退出圈子                   |
| 管理员 | 成员能力、管理圈子与频道、发布公告、设置精华与置顶、访问管理频道、移除普通成员 |
| 圈主   | 管理员能力、任免管理员、解散圈子                                               |

圈主不能直接退出，需要在设置页确认解散。删除圈子、频道和移除成员都有明确确认步骤。操作层校验角色与频道访问权限；这些校验仅为前端演示，真实接入时必须由后端再次验证。

## 工程与存储

- 页面、频道、状态与演示数据位于 `src/features/circles/`，路由生成集中在 `routes.ts`。
- `CircleProvider` 与现有 `ContentProvider` 桥接，保留旧组织 ID、加入记录与用户创建数据；旧组织路由跳转至对应圈子页面。
- 新频道、消息、帖子、成员修改与报名保存在 `circles-state-v1`。读取时校验数据结构，写入失败显示错误并保留输入。
- 帖子的 `featured` 与 `pinned` 为可选字段，兼容旧存储；已有示例内容补齐缺省标记，明确取消后的 `false` 状态会保留。访客不读取圈内帖子，成员首页不展示管理频道内容。
- 使用稳定的 `me` 身份判断内容归属，修改昵称或头像不会改变权限。
- 无效圈子、频道和帖子有恢复入口，二级页面不显示主导航。

真实圈子的新页面位于 `src/features/platform/circles/`。旧演示的活动、语音、资料库和实时文字聊天尚未迁入圈子服务，不能把此处本机回执当作服务器成功。
