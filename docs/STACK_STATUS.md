# 本地全栈交付记录

日期：2026-10-27。当前第八轮接通真实圈子活动、限额报名、顺序候补、登记清理、管理名单和独立平台治理，活动通知加入现有收件箱，共17类。真实圈聊/语音/资料、商城、影音、阅读和AI仍需继续接入后端；对象存储和高流量容量未验收。

## 实际运行与数据升级

前台5173、React运营后台5174、Go API 0.8.0 / 8080、项目私有PostgreSQL16 / 55432均已运行。后台系统状态显示schema v8及能力中文名称。

运行数据使用权威规范化表，旧聚合表更名为 `gongming_legacy_state_v1` 留存，运行时不依赖它。历次升级均先停写并备份，再事务迁移；回退需要恢复完整数据库与对应媒体检查点，不能直接让旧API写新版库。

本轮升级前先成功隔离恢复v7完整bundle（19条媒体元数据、11文件）。活动和通知联调后，v8中间检查点的37张表投影、12文件哈希及旧Cookie在重启后保持一致。其余回归完成后再次停写，最终bundle隔离恢复25条媒体元数据和14个有效文件成功；随后重启，37张数据表完整投影、14文件SHA-256及最早旧Cookie全部保留，包含活动/登记/成功收据、通知/readAt与序号。含迁移元数据共有38张gongming表。临时恢复库/目录均清理，运行库没有被恢复演练覆盖。

消息五个端点、WebSocket outbox、图片GET/HEAD、通知和全部10个活动端点使用独立SQL。普通业务读取使用REPEATABLE READ，写入使用SERIALIZABLE并完整重试。活动历史不进入State，成员/账号变化在来源事务内窄域协调登记。圈子元数据、设备及会话管理等仍有全域快照成本；消息全局outbox游标、通知每账号计数器和活动/圈管理行锁各有串行点，尚无生产吞吐承诺。

## 当前产品行为

- 主社交、通讯录和我使用真实账号；成员目录、资料、公开世界、好友申请与双向关系由服务端保存。本机 `/social/demo`、`/contacts/demo`、`/world/demo` 独立保留，网络失败不会伪装为本机成功。
- 好友申请支持接受/拒绝/撤销，移除保留私聊。群组/广播频道支持所有者改名、增删成员、转交，普通成员退出；频道只当前所有者发布，全站admin不自动越权。添加成员会开放原会话历史。
- 消息有会话seq、clientId幂等、历史游标、未读和个人已读水位；失败/刷新后的待发手动重试。事务outbox提供跨实例WebSocket、重放、过期resync、心跳和注销关闭，断线保留轮询。
- API、WS和客户端都隔离预期账号；移除成员后发送前复核，旧排队事件及迟到读取/发送回执不能恢复私密内容。角色变化关闭过期确认框。聊天输入区外部透明、顶部紧凑，但本轮未做浏览器视觉验收。
- 登录设备列出本人有效会话，单项/其它/当前会话可撤销并关闭受影响连接；旧时间不虚构，「最近验证」只记录登录。前后台请求20秒期限覆盖响应体，超时写入提示先刷新确认；迟到401、账号切换与卸载结果不能影响新账号。
- 世界支持最多9张真实JPEG/PNG，服务端应用方向并重编码，图帖先待审。图片私有存储与当前引用鉴权已接通，屏蔽原图同时隐藏两域已发布引用，解封不自动恢复帖子。
- `/account/uploads` 查询本人图片状态/引用/分页。圈内引用可明确确认删除整篇本人圈帖，成功后刷新引用且保留原图；作者离圈、被移除或失去管理频道权限后仍可清理本人引用。失败可重试，403/404可刷新；原图仅在全部引用为零后允许删除。
- `/account/uploads?image=media_<32小写hex>` 精确定位本人未删资产。切换图片、账号或卸载时废止旧请求；通知不会直接请求屏蔽图，未知/他人ID不保留旧卡片。
- `/circles` 是真实公开介绍、我的圈子和申请目录，详情 `/circles/s/:circleId`；本机 `/circles/demo` 与旧组织深链独立保留。新空开发库有标明开发示例的公私圈、成员、频道、文字与通知，已有库不补种。
- 圈子支持开放/审批加入、限时限次/撤销邀请、角色、封禁、转交、退出、归档、讨论/公告、置顶/精华和评论点赞。平台运营角色不自动成为圈成员；私圈旧申请与创建回执仍重查介绍权限。圈图绑定所属圈，普通读取按当前成员和频道授权；后台通过独立治理入口处理私圈内容。
- 社交顶部铃铛进入 `/notifications`，五个主导航不变。17类通知涵盖好友请求/决定、世界互动/审核、圈子申请/决定/身份/状态/互动/审核、媒体审核、举报结案及活动更新/递补/审核；不重复聊天未读。
- 通知与业务/审计同事务提交，按recipient/eventKey去重，点赞按actor+帖子终身去重。历史通知不存正文、圈名、审核note或邀请token；当前失权时actor/context/target全部清空，系统通知不暴露审核者。公开圈通知上下文也要求当前成员或本人pending申请。
- 通知支持分类、未读、分页、单条已读和截至列表快照全部已读。throughId绑定列表快照内本人全收件箱最高序号，旧水位不覆盖新到通知，null不改任何行，重复单条已读保持首次时间。失权结果整体替换，不合并保留旧链接；已读失败不显示假成功，图片审核可跳本人指定上传记录。
- 个人文档显式选择备份/恢复并以revision保护冲突。测试GEM已有原子双边账本与幂等，但没有现金价值；公开钱包连接不替代签名登录、支付或链上资产服务。
- 真实圈首页「活动」进入独立列表、详情、创建/编辑及管理名单；不复用本机演示，也不更改讨论/公告频道枚举。活动仅当前圈成员可读，普通成员只看本人登记，平台治理只读聚合人数。报名、候补、取消、内容编辑和平台治理均以服务器回执为准。
- 活动最多提前365天、持续168小时、容量1–1000、每圈最多20个未结束且未取消活动。最后名额按活动行锁竞争；候补显式同意自动递补，释放或恢复可见性时仅递补有效且未截止者，不复活已取消登记。报名成功收据永久防重放，取消活动为终态。
- 成员退出/移除/封禁或账号停用，同事务释放未结束活动登记；重新加入不恢复。暂停/归档保留已有约定但阻止新报名。失权者持已知ID仍可盲清理本人登记，入口不读取标题/地点或名单；同页报名、清理和取消活动互斥，清理成功仅通知仍挂载的合法详情废止旧读取并刷新。
- 活动管理带revision避免覆盖并发改动，冲突保留草稿且重新载入需确认。后台屏蔽/恢复须说明与确认，取消活动只读；恢复不延长截止。活动创建者离圈仍能收到通用审核结果，正文与跳转按当前权限脱敏。真实示例保留确认、候补、取消历史及线上活动，地点均明确标为开发示例。

本轮运行中真实代理联调共47组通过：活动12组、通知8组、圈子8组、通用HTTP8组、实时消息与设备11组。活动覆盖容量并发、候补/恢复递补、旧成功请求不复活、revision/名单/跨圈隔离、成员和账号失权释放、暂停盲取消、平台治理/举报、取消终态及可体验示例；三种新活动通知与原14类均实际产生并核验。旧圈子与通知脚本也实际上传、审核和清理图片；本轮未重复计入独立媒体脚本的历史8组。结果文件在Git忽略目录，仅存ID，不记录口令、Cookie、邀请token或内部说明。备份与重启完整性另有上述独立证据。

新增活动11组Go专项（10真实PG隔离、1输入单元）覆盖容量/队列/回执、时间边界、独立SQL读写、来源/通知/审计原子回滚、creator离圈审核脱敏、三表禁删证据、非UTC夏令时精确168小时，以及v7迁移旧行/文件/Cookie与失败DDL回滚。互操作强制两种快照交错；还验证旧State快照连活动本身都未见时，另一连接新建并报名后再移除/停用，完整事务会重试并释放登记。前台新增4文件47项涵盖UTC转换、冲突草稿、写互斥、失权清理与迟到回执；根路由22项通过，后台活动15项及原模块回归计入完整结果。

通知10组定向Go测试（3 memory事务adapter、7真实PG隔离）验证业务/通知/审计原子回滚、并发counter与终身去重、跨实例已读水位、身份/来源校验、无关域排他锁期间仍完成轻量操作、动态权限、媒体双域级联、不可变身份、v6迁移失败回滚/旧xmin与文件保留及首次空库示例。通知历史不进入普通State。

既有圈子9组专项覆盖私圈/跨圈、历史回执隐私、公告权限、图片审核、唯一邀请兑换、1000成员最后名额竞态与schema6原子迁移；媒体13组覆盖方向/重编码、权限/配额/幂等、未知COMMIT候选保留和目录安全。消息SQL8组覆盖五条路径在无关域锁下仍完成、契约对照、并发幂等、管理交错和outbox回滚；设备11项覆盖旧凭据兼容、撤销/迁移和旧WS事件阻断。数据库测试使用独立临时schema并清理，不修改应用表。

## 尚未验证或接通

- 浏览器控制仍被明确禁用，本轮未做截图、真实浏览器或真机布局验收；自动测试和构建不等于视觉通过。
- 当前没有Docker；容器构建、健康启动、HTTPS ingress仍需部署环境实跑。
- 通讯附件、引用/撤回、送达/对方已读、群公告/邀请审批/分级管理员与解散归档尚待完善。个人水位不是对方已读回执；圈子已有的审批/角色/归档不能被称作消息群组能力。
- 通知尚无实时订阅、系统推送/短信/邮件、删除/GC与容量验证；未来保留策略必须留下点赞终身去重证据。每账号计数器、未读索引计数及最多1000成员的圈状态扇出仍需压测。
- 媒体没有S3/CDN、缩略图、视频转码、自动孤儿清理或存储监控。文件/数据库无共享原子事务，未知提交和清理失败可留不可访问残留；单实例限额不是分布式限流或磁盘总配额。
- 活动尚无收费、签到定位、短信、日历订阅、外部会议或定时提醒；名额/候补已真实持久化，但不代表高并发票务服务。圈聊实时流、语音、资料尚未接入；匹配、商城、影音、阅读、游戏和AI仍有本机演示边界。没有真实支付、SIWE、合约或链上资产服务，邮件验证/密码找回、服务端隐私/黑名单、监控和生产压测仍待实现。
