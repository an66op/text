## 当前产品行为

- 登录后的主社交使用真实账号消息；成员目录可搜索、查看资料、发起私聊和举报。个人页与桌面头像同步账号资料，本机资料不被登录覆盖。
- 通讯录使用「好友 / 申请 / 发现」三页签。申请支持附言、接受/拒绝/撤销、方向筛选与徽标；接受原子建立唯一双向关系，移除不删除原私聊。列表与资料支持可见轮询和手动刷新，申请数量不变但对象变化也会更新。
- 群组和频道右上角进入独立聊天信息路由，支持所有者改名、添加/移除、转交；普通成员可退出。只有当前频道主发布，平台 admin 不自动越权。新成员可阅读该会话原有历史，页面有明确说明。
- 本机社交与通讯录保留 `/social/demo`、`/contacts/demo`；访客可体验本机内容，服务不可达时显式提示，不能以演示替代服务器结果。
- 消息有每会话 seq、clientId 去重、稳定历史游标、未读与可见消息已读水位。失败/刷新后的待发需手动重试并复用 ID，草稿按账号和会话隔离。
- 手机端消息顶部、连接状态和输入区悬浮于滚动内容上；输入框外透明，框内保留玻璃效果。动态测量实际高度，已读判断排除被遮挡区域，加载历史保留阅读位置。
- WebSocket 使用事务 outbox、最小失效通知、跨实例读事件、重放、过期resync、心跳和注销关闭；断线时显示状态并保留轮询。API 与 WS 都验证预期账号，防同域多标签页 Cookie 换账号串写。
- 移除/退出同步清理个人水位；服务端在发送前再次鉴权，已排队旧事件会被丢弃，被移除者仅收到无会话 ID 的个人 resync。详情页忽略普通聊天通知，避免忙碌群组让元数据请求一直失效；角色变化关闭过期确认框。
- 客户端收到权限拒绝会同时废止最新/历史读取和旧发送回执；迟到200不能恢复已清除内容。重新加入需要新的服务器读取成功；普通消息通知合并刷新，繁忙群组也会呈现当前合法会话列表，最多一个读取在途。
- 个人备份、世界、运营审核与测试积分沿用实际 PostgreSQL 数据；测试积分没有现金价值，公开钱包连接不替代签名认证。
- 「账号 → 登录设备」及「设置 → 账号安全 → 登录设备」读取本人真实有效会话，支持单项/其它/当前会话撤销。成功后更新列表，失败保留记录与重试；旧账号迟到结果不能恢复已撤销设备或影响新账号。设备名称为粗粒度提示，每项代表登录会话；最近验证只记录登录验证时间。
- 前后台请求20秒期限覆盖响应体读取，取消可及时结束等待，写入超时提示先确认结果且不自动重发。晚到401和私密响应不能影响新账号；卸载后的旧操作不能再发请求；登录期间遇到401或旧会话到期，会在操作结束后重查 Cookie。后台可见时定期验证，临时断网保留已知身份并显示重试。
- 世界发布器支持最多9张实际JPEG/PNG、串行上传、本地预览、明确状态与同clientId重试；不伪造百分比或自动发帖。上传图帖先待审，作者可打开详情刷新审核状态；待审/隐藏帖不提供公开互动。关闭或切账号会释放预览/取消请求，迟到上传、删除或发帖回执不能污染新账号。
- 「我的上传」能查询、筛选、分页和清理未引用图；服务端成功后才移除卡片。屏蔽图不发普通端原图请求。后台新增图片管理，要求处理说明及具体确认，屏蔽原图同时隐藏已发布引用帖，解除屏蔽不自动恢复帖子。
- 发现的 `/circles` 使用真实公开介绍、我的圈子与申请目录，真实详情位于 `/circles/s/:circleId`。本机圈子保留 `/circles/demo`、`/circles/demo/new` 和原组织深链；两套数据互不替代。新空开发库有明确标注的真实公私圈文字、成员、频道与待审申请示例，已有库不自动补种。
- 圈子支持公开/私密、直接/审核加入、邀请过期/限次/撤销、任免管理员、移除/封禁/解禁、转交/退出和归档。普通成员不返回管理频道，平台运营身份不自动成为圈成员；私圈历史申请与原创建回执也重查当前介绍权限。
- 圈内讨论/公告、图文、精华/置顶、评论/点赞及举报由服务端保存。公告主帖只圈管理可发，成员可讨论。圈图绑定所属圈，待审后按当前成员与频道授权读取；不能向世界或其它圈引用。后台独立暂停圈子、审核私圈帖子，图片屏蔽联动隐藏两域已发布引用，世界公开与圈内引用分别计数。
- 圈页面失权后卸载私密业务树，旧读取/写入回执不能恢复内容；上传失权同步中止队列。帖子成功更新会废止旧轮询回执，同圈切帖/频道重挂业务状态。频道完整取50条上限，邀请独立分页，不因默认30条丢失管理入口。

## 尚未验证或接通

- 当前 Work 设置仍明确禁止本地浏览器控制，inventory为空。本轮未做截图、真实浏览器或真机布局验收；交互测试/构建不代替视觉验收。
- 当前没有Docker。本轮补齐两层Nginx WebSocket升级头与心跳超时，但容器构建、健康启动及HTTPS ingress尚需部署环境实跑。
- 附件、引用/撤回、送达/对方已读状态、群公告/邀请审批/分级管理员及解散归档仍待服务端完善；当前个人水位不等于对方已读回执。
- 媒体当前为真实私有目录存储与人工审核；没有S3/CDN、缩略图、视频转码、自动孤儿清理或存储监控。数据库与文件不共享原子事务，未知提交/清理失败可留不可访问残留；单实例额度不等于分布式限流或磁盘配额。圈子普通读写仍有State全域快照成本，实时圈聊/语音/活动/资料尚未接入；匹配、商城、影音、阅读和AI仍有本机演示能力。
- 没有真实支付、SIWE、合约或链上资产服务；尚需独立总账审计/外部对账、邮件验证与密码找回、监控告警、分布式限流和压力测试。
